# Catalis feature modules

Catalis is a static web app (one `index.html` built by `python3 build.py`) for Vietnamese learners of IELTS, Academic and General Training, band 4.5 to 8. UI text is Vietnamese; exam material is English.

Each `src/features/*.js` file is pasted, in filename order, inside the app closure in `src/app.js`, right before the boot section. So a module can use every helper below directly and must NOT wrap itself in an IIFE or use import/export. Every `src/features/*.css` file is appended to `src/app.css`. Prefix your top-level names (e.g. `LS_` for listening, `RD_` reading, `WR_` writing, `SP_` speaking, `GR_` grammar, `PR_` pronunciation, `GM_` games, `TS_` tests) and your CSS classes the same way (`.ls-`, `.rd-`...).

Register a view: `VIEWS.listen = el => { el.innerHTML = '<div class="view">...</div>'; ... }` (may be async). Navigation and the top bar are already handled; views in use: listen, read, write, speak, test (group "Luyện"); games (group "Ôn tập"); grammar, pron (group "Tra cứu"). Navigate with `go('name')`. When the user leaves your view, `window.__leave` (if you set it) is called: use it to stop timers, recognition, audio.

## Helpers (from app.js)
- DOM: `$(sel, root)`, `$$(sel, root)` (array), `esc(str)`, `toast(msg)`, `modal(html)` -> `{el, close}`, `ic(name)` icon svg (names: house layers target search user-round headphones mic book-open pen-line puzzle clipboard-check book-a type audio-waveform shapes landmark play square volume-2 x check flame zap award a-large-small notebook-pen gamepad-2 settings chevron-right chevron-left lightbulb snail rotate-ccw cloud sparkles trophy calendar-check clock repeat languages users timer bar-chart message-circle circle-stop graduation-cap)
- `SPK` speaker svg for `.spk` round buttons. Any element with `data-say="text"` speaks it on click (optional `data-lang="en-AU"`, `data-voice="m"`).
- Random: `shuffle(arr)`, `pick(arr)`. Dates: `DAY`, `today()`, `ymd(ms)`. Text: `viFold(s)`, `enFold(s)`, `countWords(text)`, `fmtTime(seconds)` -> "mm:ss".
- Data: `await loadJSON('listening'|'reading'|'writing'|'speaking'|'grammar'|'pron'|'daily')` (cached). Vocabulary: `V` (array), `VI` (Map lowercase word -> word), word = `{w, ipa, pos, vi, ex, exvi, col:[...], fam, em, topic, lv, k}`; `await loadAllVocab()`; `LV_NAME`, `openWord(k)`.
- Answer checking: `checkAnswer(input, "carbon dioxide|CO2")` -> bool (ignores case, punctuation, leading article, number words vs digits, ordinals). `normAns(s)`.
- Band: `bandOf('listening'|'reading', raw, total=40, exam?)` -> band (reading uses Academic or GT table from `examType()`), `overallBand([b1,b2,...])`, `fmtBand(b)`, `examType()` -> 'academic'|'general'.
- Progress: `P` (state object, add your own sub-object e.g. `P.ls = P.ls || {}`), then `touch('main')` to save and sync.
- XP: `award(kind, n)` after real learning actions. kinds and weights: listen 1.5/question, read 1.5/question, write 25/task submitted, speak 4/answer recorded, grammar 8/point learned, pron 2/item, test 30/full test finished, game 1/correct, review 1. The daily plan counts `plDay().listen >= 10`, `read >= 13`, `speak >= 3`, `write >= 1`, `grammar >= 1`, `test >= 1`, so award with those kinds.
- Scores: `recordScore({skill:'listening'|'reading'|'writing'|'speaking'|'overall', band, raw, total, id, title})` whenever a learner finishes a full part/passage/test or gets an AI band. `latestBands()`, `estBand()`.
- Mistakes notebook: `window.__mistake('q', {q:'question text', o:[options] (optional), a: index or 'answer|alt', w:'Vietnamese explanation', src:'Listening Test 1 Part 2'})` on every wrong answer; `window.__mistOk(item)` on a correct one.
- Quiz runner: `runQuiz(el, {title, items:[{q, o?, a, w}], kind:'grammar', onDone(score,total)})` renders a one-question-at-a-time quiz into `el` (mcq if `o` is an array, otherwise a typed gap fill).
- Timer: `makeTimer(seconds, onTick(left), onEnd)` -> `{stop(), left()}`. Style with `<span class="timer-chip">` (add class `low` near the end).
- Speech out: `await say(text, {lang:'en-GB'|'en-AU'|'en-US', voice:'f'|'m', rate})` resolves when finished; `stopSay()`. Rate defaults to the user's setting (`P.settings.voiceRate`).
- Speech in: `listen({lang:'en-GB', onText(text, isFinal), onEnd(finalText)})` -> `{stop()}` or `null` if the browser has no SpeechRecognition (then show a textarea fallback: "Trình duyệt này không nhận giọng nói, hãy dùng Chrome hoặc Edge, hoặc gõ câu trả lời"). `await recorder()` -> `{stop(): Promise<blobURL>}` or null, for playing back the learner's own recording.
- AI (Groq, behind the group password): `AI` is null when not available. `await ask(prompt, {onText({text})})` -> `{text}`, `await askJSON(prompt)` -> parsed JSON. Wrap in try/catch and show `aiError(e)` (Vietnamese message). Elements with class `need-ai` are hidden when AI is off, `.no-ai` shown; call `refreshAIBits()` after rendering. Keep prompts under ~50k characters. Ask the model to answer in Vietnamese for explanations and English for corrected text, with no em dash.
- Mascot: `mascot(state, size)` html, `mcSay(state, html, size)` speech bubble. States: calm hi idea yay ok hmm zzz.
- UI pieces: `subTabs(id, [[key,label],...], cur, onPick)` returns html for a row of tab chips. `levelChips` exists for vocab levels.
- Celebration: `confetti()`.

## Existing CSS classes (use them; add your own prefixed ones in your .css file)
`.view` (page column, flex gap), `.panel` (card), `.spread` (row space-between), `.row` (wrap row), `.grid2`, `.grid3`, `.btn`, `.btn.primary`, `.btn.sm`, `.btn.ghost`, `.chip` (+ `aria-pressed="true"`), `.pill`, `.pill.ai`, `.label` (small caps label), `.note` (muted small text), `.small`, `.muted`, `.num`, `.opts` + `.opt` (answer buttons; add class `right` / `wrong` after answering, the shell plays sound and animation), `.fb.ok` / `.fb.bad` (feedback box), `.spk` (round speaker button), `.ex` (example sentence block), `.en-s` (English reading text, serif 17px), `.ai-out` (pre-wrap AI text box), `.empty`, `.timer-chip`, `.kbd`, `details.g` with `summary`. h2 for page title, h3 for panel titles.
Tokens: --bg --surface --sunk --line --line2 --ink --muted --accent (navy) --accent-ink --accent-soft --orange --orange-soft --t1 (red) --t2 (amber) --t3 (green) --t4 (blue) --t5 (grey) and their -soft, --ok --ok-soft --bad --bad-soft --warn, --f-body --f-en (serif for English passages), --r --r-lg. Light and dark themes must both work: never hard-code colors except inside SVG charts where you still read tokens via `var(--...)`.
Mobile width 390px must not scroll horizontally (wrap long tables in a div with `overflow-x:auto`).

## Data files (data/*.json)
Schemas are in `content/CONTENT_SPEC.md`. Summary:
- `listening.json`: array of 24 parts `{id:'l1p1', test, part, title, setting, speakers:[{id,name,voice:'f'|'m',accent}], lines:[[speakerId,text]], groups:[{kind, instr, opts?, items:[{q, a, o?, why}]}]}`. kinds: form, note, table, sentcomp (q has "___", a "ans|alt"), mcq (o = 3 options, a index), matching (group opts, a index), multi (choose TWO, o = 5 options, a = [i,j], counts 2 questions). 10 questions per part, 6 tests x 4 parts.
- `reading.json`: 18 passages `{id, type:'academic'|'general', test, section, title, topic, band, paras:[[label,text]], groups:[{kind, instr, opts?, items:[{q, a, o?, why, para}]}], vocab:[[en,vi]]}`. kinds: tfng (a TRUE/FALSE/NOT GIVEN), ynng, mcq (o 4, a index), headings (group opts, q "Paragraph B", a index), matchinfo (a paragraph letter), matchfeat (opts, a index), sentcomp/sumcomp/notecomp/shortans (q with "___", a "ans|alt"). Academic tests 1-4 (3 passages each), General tests 1-2 (3 sections each).
- `writing.json`: `{t1a:[{id,title,chart,prompt,model,overview,notes,phrases}], t1g:[{id,tone,prompt,model,notes,phrases}], t2:[{id,type,topic,prompt,outline,ideas:{for,against},model,vocab}]}`. chart: `{type:'line'|'bar'|'pie'|'table',title,unit,x:[...],series:[{name,values}]}` or `{type:'process',title,steps:[...]}` or `{type:'map',title,before:{year,items},after:{year,items}}`.
- `speaking.json`: `{p1:[{topic, qs:[...], samples:[[q,a]]}], p2:[{id, card, bullets:["You should say:",...], explain, topic, sample, vocab:[[en,vi]], p3:[...5 questions], p3samples:[[q,a]]}]}` (30 Part 1 topics, 40 cue cards).
- `grammar.json`: 60 points `{id, lv:1|2|3, cat, title, en, form, explain, ex:[[en,vi]], mistakes:[[wrong,right,why]], ielts, quiz:[{s:'sentence with ___', o:[4], a:index, w}], fix:[{s:'sentence with one error', a:'corrected', w}]}`.
- `pron.json`: `{sounds:[44 x {ipa,type,name,ex:[words],how,vn,pairs:[[a,b]]}], rules:[15 x {id,title,body,examples:[[word,note]],quiz:[{q,o,a,w}]}], minimal:[23 x {id,contrast,pairs:[[a,b]...]}]}`.

## Rules
- Vietnamese UI text, plain and natural, addressing the learner as "bạn". No em dash character, no unicode arrows (write "->"). No alert/confirm/prompt dialogs.
- No external network calls except the helpers above (api via ask/askJSON) and no new CDN libraries.
- Test: `python3 build.py`, then `PORT=<your port> SHOTS=/tmp/shots-<you> python3 tools/smoke.py <your views>` (prints JS errors and horizontal overflow at 390px and 1200px, saves screenshots). Open the screenshots with the Read tool and look at them. For interactions, write your own short Playwright script (PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers) that clicks through the main flow at 390px and checks there are no page errors.
- Other modules are being written at the same time by other people; only edit your own files. If the build or a smoke run shows an error clearly coming from another module, ignore it.
